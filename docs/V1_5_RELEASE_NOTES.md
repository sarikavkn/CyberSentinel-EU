# CyberSentinel EU v1.5 Release Notes

## Product milestone
This is the Enterprise Compliance Core milestone. It turns the regulatory starter catalog into an interactive workflow for organisation screening, requirement assessment, evidence integrity, findings, risk and assets.

## Regulatory design principles
- Legal source and software control are separate entities.
- Applicability screening returns likely/review outcomes, never automatic legal certification.
- Directives require Member-State transposition packs.
- Implementing/delegated acts are versioned separately from Level 1 legislation.
- Guidance such as ENISA implementation material can help define evidence/tests but is not represented as binding law by itself.
