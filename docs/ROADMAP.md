# CyberSentinel EU Roadmap

## v1.5 — Enterprise Compliance Core (this package)
Organisation onboarding, scope screening, interactive assessments, evidence hashing, findings/remediation, risk register, assets, audit UI, CSV export and PostgreSQL-ready configuration.

## v2.0 — Production Platform Core
Alembic migrations, enterprise SSO/MFA, tenant isolation, PostgreSQL-only production profile, encrypted object-storage evidence vault, malware scanning, workflow/approvals, email/webhook notifications, background workers, secrets manager, immutable audit sink and production observability.

## v2.5 — EU Regulatory Depth
Member-State NIS2 transposition packs, DORA Level 2 acts, CRA product/economic-operator applicability, sector packs, regulatory version diffing and controlled legal-content review workflow.

## v3.0 — Continuous Compliance
Connectors for IAM, SIEM, EDR, vulnerability scanners, cloud platforms, backup platforms and ticketing. Automated control tests generate evidence and findings with human verification.

## v4.0 — Security Operations Extension
Asset discovery, vulnerability prioritisation, incident case management, telemetry integrations, detection correlation and approval-controlled response workflows.
